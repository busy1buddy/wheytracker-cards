# wheytracker-cards

Daily PNG snapshots from [busy1buddy/wheytracker](https://github.com/busy1buddy/wheytracker) - a private price tracker for AU whey-protein retailers.

This public repo exists only to host the daily card images so they can be embedded in private GitHub Issues on wheytracker. raw.githubusercontent.com requires auth for private repos, so a separate public repo is the cleanest workaround.

Each PNG in cards/YYYY-MM-DD.png is the same daily card embedded in the wheytracker daily summary issue.

Generated automatically by a OnePlus 8 Pro running as a self-hosted always-on host. This is just an asset CDN - nothing here means anything without context.
